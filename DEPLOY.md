## OPTION 1: GitHub Pages (Recommended - 5 Minutes)

### Step 1: Create GitHub Account
- Go to **github.com**
- Click "Sign up" (if you don't have account)
- Or "Sign in" (if you do)

### Step 2: Create Repository
1. Click **"+"** icon (top right)
2. Click **"New repository"**
3. Repository name: `stock-academy`
4. Select **"Public"**
5. Check **"Add a README file"**
6. Click **"Create repository"**

### Step 3: Upload Files
1. Click **"Add file"** button
2. Click **"Upload files"**
3. **Drag all 4 files** onto the page
4. Scroll down
5. Click **"Commit changes"**

### Step 4: Enable Pages
1. Click **"Settings"** (top menu)
2. Click **"Pages"** (left sidebar)
3. Under "Source": select **"main"**
4. Click **"Save"**

### Step 5: Get URL
1. Wait 2 minutes
2. Refresh the Settings → Pages page
3. You'll see: **"Your site is live at..."**
4. Click that URL
5. **Your game should work!**

### Step 6: Install on iPhone
1. Open the URL in **Safari** (must be Safari)
2. Tap **Share** button (square with arrow)
3. Scroll and tap **"Add to Home Screen"**
4. Tap **"Add"**
5. App appears on home screen!

## TROUBLESHOOTING

### "Blank screen"
- Open browser console (F12)
- Check for red errors
- Make sure all 4 files uploaded
- Check files are in root directory (not subfolder)

### "Nothing happens when I click buttons"
- `app.js` didn't load
- Check browser console for errors
- Make sure file is named exactly `app.js`

### "Styles look broken"
- `styles.css` didn't load
- Check file is named exactly `styles.css`
- Check it's in same folder as `index.html`

### "Can't add to iPhone home screen"
- Must use **Safari** browser (not Chrome)
- Must be iOS 11.3 or higher
- Try clearing Safari cache first
